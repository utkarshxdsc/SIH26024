## 🪓 THE FORMULA — SHARPENED, NOT HIDDEN

</div>

```
Risk(mine) = 0.25 × UnresolvedCount + 0.30 × SeverityLoad
           + 0.20 × InspectionStaleness + 0.15 × RecurrenceRate
           + 0.10 × ResolutionDelay
```

<div align="center">

| Weight | Value | Signal | Why it swings this hard |
|:------:|:-----:|--------|--------------------------|
| **w₁** | `0.25` | Unresolved violations | Open wounds don't heal themselves |
| **w₂** | `0.30` | Severity load | One deep cut beats ten scratches |
| **w₃** | `0.20` | Inspection staleness | Nobody's watching = nobody's safe |
| **w₄** | `0.15` | Recurrence rate | Repeat offenders get hit harder |
| **w₅** | `0.10` | Resolution delay | Slow fixes bleed risk over time |

> 🎯 **LOW** (0-34) → **MEDIUM** (35-59) → **HIGH** (60-79) → **CRITICAL** (80-100) — no mine hides in the middle for long

## 🪓 ARM YOURSELF — GETTING STARTED

</div>

### Prerequisites
```bash
Python ≥ 3.10  ·  Node.js ≥ 18  ·  npm
```

### Swing #1 — Backend
```bash
cd backend
pip install -r requirements.txt
python -m app.seed_data          # loads 12 mines, ready to be judged
uvicorn app.main:app --reload --port 8000
# → live docs at http://localhost:8000/docs
```

### Swing #2 — Frontend
```bash
cd frontend
npm install
npm start
# → command deck at http://localhost:3000
```

Both running, two terminals, no shortcuts. That's the whole weapon assembled.
