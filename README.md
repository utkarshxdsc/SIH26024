## ⚡ What is KhanRakshak?

</div>

**KhanRakshak** *(from Hindi* **खान** *— Mine +* **रक्षक** *— Guardian, Protector)* is an AI-based smart governance and compliance monitoring platform built for **Smart India Hackathon 2026 — SIH26024**, sponsored by the **Ministry of Coal**. It replaces slow, paper-driven, manual mine inspections with a living digital nervous system — fusing **CCTV computer vision, IoT sensor telemetry, and a statutory rule engine** to catch safety and environmental violations in coal mines the moment they happen, not weeks later in an audit file.

<div align="center">

```
┌───────────────────────────────────────────────────────────────────────┐
│  ⛏️ Violation Occurs  →  📡 Sensors/Cameras Detect  →  🤖 AI Flags   │
│  📜 Rule Engine Checks →  🚨 Authority Alerted       →  ✅ Compliance │
└───────────────────────────────────────────────────────────────────────┘
```

</div>

## 🧮 Mine Compliance Scoring Model

</div>

The governance engine computes a **weighted compliance risk score** per mine:

```
R(mine) = w₁ × (safety_violations / max_safety) + w₂ × (env_violations / max_env)
        + w₃ × (sensor_risk_index) + w₄ × (repeat_offense_factor)
```

<div align="center">

| Weight | Default | Factor | Rationale |
|:------:|:-------:|--------|-----------|
| **w₁** | `0.35` | Safety Violations | Worker life & limb protection |
| **w₂** | `0.25` | Environmental Violations | Ecological & community impact |
| **w₃** | `0.25` | Live Sensor Risk | Real-time hazard conditions |
| **w₄** | `0.15` | Repeat Offense Factor | Chronic non-compliance pattern |

> 🎛️ Weights are **configurable by regulators** to reflect evolving DGMS priorities

</div>

## 🔥 Multi-Hazard Risk Categories

</div>

<div align="center">

| 🎥 PPE / Safety Risk | 🔥 Fire & Gas Risk | 🏔️ Structural Risk | 🌊 Environmental Risk |
|:---------------------:|:-------------------:|:--------------------:|:-----------------------:|
| **35%** weight | **25%** weight | **20%** weight | **20%** weight |
| Vision-detected gear/zone breaches | CH₄/CO thresholds, smoke events | Subsidence, slope, blast proximity | Discharge, dust, noise limits |

</div>

> Detection pipeline combines **CCTV frame sampling + sensor fusion** to cross-verify vision alerts against live telemetry before escalation, cutting false positives.

## 🚀 Getting Started

</div>

### Prerequisites

```bash
Node.js ≥ 18  ·  npm or pnpm  ·  Python ≥ 3.10 (for vision service)
```

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/utkarshxdsc/SIH26024.git
cd SIH26024

# 2. Install frontend dependencies
npm install

# 3. Configure environment (optional — can be set in-app)
echo "VITE_MAPS_API_KEY=your_maps_key_here" > .env
echo "VITE_VISION_API_KEY=your_vision_key_here" >> .env

# 4. Start development server
npm run dev
# → http://localhost:5173/
```

<details>
<summary><b>📦 Environment Variables Reference</b></summary>

<br/>

| Variable | Required | Description |
|----------|:--------:|-------------|
| `VITE_MAPS_API_KEY` | Optional | Mapping provider key for mine visualization |
| `VITE_VISION_API_KEY` | Optional | Computer-vision inference endpoint key |

> **Note:** Keys can be entered directly in the console UI and are kept local to the session.

</details>
